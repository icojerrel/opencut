# Client Communication

## Templates per situatie

### Eerste reactie op interesse
- Bedank voor de interesse
- Bevestig beschikbaarheid
- Stel 2-3 discovery-vragen
- Max 150 woorden

### Follow-up (geen reactie na 3-5 dagen)
- Kort, niet pushy
- Voeg waarde toe (tip, relevant artikel, of status update)
- Eén duidelijke CTA

### Scope-wijziging
- Erken het verzoek
- Leg impact uit (tijd + kosten)
- Bied opties: A) uitbreiding tegen meerprijs, B) fase 2 apart, C) huidige scope behouden
- Wacht op schriftelijke goedkeuring vóór start

### Factuurherinnering
- Vriendelijk → formeel escalatiestappen
- Dag 0: factuur verstuurd
- Dag +7: vriendelijke reminder
- Dag +14: formele herinnering met vervaldatum
- Dag +21: laatste waarschuwing

### Project afronding
- Lever overzicht van wat is opgeleverd
- Vraag om feedback/review
- Bied optionele onderhoudsperiode aan

## Toon

- Professioneel maar menselijk
- Geen corporate jargon
- Actieve zinnen, korte alinea's
- Altijd een duidelijke volgende stap

## Taal

Schrijf in de taal van de klant. Default Nederlands tenzij opdracht/klant Engels is.

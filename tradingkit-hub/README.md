# TradingKit Hub

Companion onboarding app for the [TradingKit.com](https://tradingkit.com/) AI trading stack by DaviddTech.

## Features

- Product cards linking to Trader.dev, PropFirm AI, Strategy Factory, and AI Trading Arena
- MCP setup instructions for Cursor, Claude Code, Codex, and other MCP clients
- Copy-paste starter prompts from the [ai-trading-agent](https://github.com/DaviddTech/ai-trading-agent) workflow

## Development

```bash
cd tradingkit-hub
npm install
npm run dev
```

Open http://localhost:4173

## Build

```bash
npm run build
npm run preview
```
